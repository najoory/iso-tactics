# PixelLab Artist

## Overview
This skill provides expert guidance for generating high-quality, game-ready pixel art assets using the PixelLab MCP server. It covers character creation, directional views, autotiling, and custom animations.

## Specialized Workflows

### 1. Character Creation
- **Standard Mode**: Best for generic humanoid/quadruped units. Supports 4 or 8 directions.
- **Pro Mode**: Recommended for "Hero" units or complex designs. Higher quality, uses reference-based generation. Always 8 directions.
- **Views**: Use "low top-down" to match the project's isometric perspective.

### 2. Consistent Tilesets
When creating terrain transitions (e.g., Grass to Dirt), always chain tilesets for visual consistency:
1. Create the first tileset (e.g., `create_topdown_tileset` for "grass" to "dirt").
2. Retrieve the `base_tile_id` for the "dirt" from the completed job.
3. Use that ID as the `lower_base_tile_id` for the next transition (e.g., "dirt" to "stone").

### 3. Custom Animations
- **Template Mode**: Fast and cheap (1 generation/direction). Use for standard actions like `walk`, `run`, `idle`.
- **Custom Mode**: Expensive (20-40 generations/direction). Requires `action_description` and **explicit user confirmation** of the cost before proceeding.
- **Process**: Always call `animate_character` without `confirm_cost=true` first to show the cost to the user.

## Asset Integration
- **Folder Structure**: Units should be stored in `assets/units/<unit_name>/`.
- **Rotations**: Ensure all 8 directions are exported to the `rotations/` subfolder.
- **Metadata**: Keep the `metadata.json` generated by PixelLab to facilitate future state variants or animations.

## Best Practices
- **Directional Consistency**: For objects, use `directions=8` if the player will rotate around them. Use `directions=1` for static map decorations.
- **Styling**: Prefer "selective outline" and "medium shading" to match the project's current aesthetic.
- **Sizes**: Use 48px or 64px base sizes for units to maintain high detail while keeping the canvas manageable.
